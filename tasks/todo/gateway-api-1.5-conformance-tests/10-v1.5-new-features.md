# Gateway API v1.5.0 新增/变更测试 (相比 v1.4.x)

## 新增 Features

### ListenerSet (10 tests, 全新)
Gateway API v1.5 引入 ListenerSet 资源，允许将额外 listener 动态附加到现有 Gateway。
- 需要 Gateway 显式配置 `spec.allowedListeners` 才能使用
- 支持命名空间隔离控制 (None/Same/Selector)
- 支持与 Gateway 原有 listener 的冲突检测

### CORS 支持 (2 tests, 全新)
- `HTTPRouteCORS` - 完整 CORS preflight + 普通请求处理
- `HTTPRouteCORSAllowCredentialsBehavior` - credentials 模式下的特殊行为

### 303/307/308 重定向状态码 (6 tests, 全新)
Gateway API v1.5 新增对非标准重定向状态码的支持:
- 303 See Other - 常用于 POST-Redirect-GET 模式
- 307 Temporary Redirect - 保留原始方法
- 308 Permanent Redirect - 永久重定向且保留方法
- 每种都有 Gateway 和 Mesh 两个版本

### TLS 混合终止模式 (1 test, experimental)
- `TLSRouteMixedTerminationSameNamespace` - 同一 TLSRoute 同时支持 Passthrough 和 Terminate
- Feature: `TLSRouteModeMixed`

### TLS Terminate 模式增强 (4 tests)
v1.5 扩展了 TLSRoute Terminate 模式的测试覆盖:
- `TLSRouteListenerTerminateNotSupported`
- `TLSRouteListenerTerminateSupportedKinds`
- `TLSRouteTerminateSimpleSameNamespace`
- `TLSRouteListenerMixedTerminationNotSupported`

### 前端客户端证书验证 (4 tests, 全新)
- Gateway 入口 mTLS 支持
- 包含正常验证、不安全回退、无效配置、跨命名空间等场景

### HTTPS Misdirected Request 检测 (1 test)
- `HTTPRouteHTTPSListenerDetectMisdirectedRequests`
- SNI 与 Host header 不匹配时返回 421

### UDPRoute (1 test)
- 基本 UDP 路由支持

## 变更的 Features

### BackendTLSPolicy
v1.5 中 BackendTLSPolicy 从 experimental 升级，新增:
- SAN 验证 (`BackendTLSPolicySANValidation`)
- 与 Gateway backendTLS 的交互

### Gateway 后端客户端证书
- `GatewayBackendClientCertificate` - Gateway 级别的后端 mTLS 配置
- 与 BackendTLSPolicy 配合使用
