# 14 - Bot Detection (Bot 检测)

**优先级**: P2 - 锦上添花

## 问题

识别和阻止恶意爬虫、自动化工具对 API 的滥用。对公网 API 有实际价值。

## 竞品对比

| 网关 | 实现方式 |
|------|---------|
| APISIX | 通过自定义插件实现 |
| Kong | `bot-detection` 插件，基于 User-Agent 正则匹配（allow/deny 列表） |
| Envoy | 无原生支持（通过 ext_authz 或 WASM 实现） |

## 需要实现

- [ ] User-Agent 规则匹配（已知爬虫 / 恶意工具的 UA 列表）
- [ ] 自定义 allow / deny 规则
- [ ] 可配置的拦截响应（403 / 自定义 body）
- [ ] 规则热更新
- [ ] 作为 HTTP 插件实现

## 备注

基础版实现较简单（UA 正则匹配）。高级版可结合行为分析（请求频率、指纹检测），但复杂度显著增加。
