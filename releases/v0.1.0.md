## Features

### Core Gateway

- **High-performance proxy** built on Cloudflare's [Pingora](https://github.com/cloudflare/pingora) framework in Rust
- **Controller–Gateway separation** — Controller handles Kubernetes/config sources and streams configuration to Gateways via gRPC; Gateway is a stateless data plane
- **Dual deployment** — runs in Kubernetes (watching CRDs) or standalone mode (local YAML), same binary
- **Hot reload** — routes, backends, plugins, and TLS certificates take effect immediately without restart or connection drops

### Protocol Support

- HTTP/1.1, HTTP/2, gRPC, TCP, UDP, WebSocket, SNI proxy

### Kubernetes Gateway API

- Full support for [Gateway API v1](https://gateway-api.sigs.k8s.io/) (v1.5.0): `HTTPRoute`, `GRPCRoute`, `TCPRoute`, `UDPRoute`, `TLSRoute`
- Path matching: Exact, Prefix, Regex
- Header, query parameter, and method matching
- Exact and wildcard hostname routing

### TLS

- mTLS, dynamic certificate loading
- ACME auto-provisioning (HTTP-01 / DNS-01)
- Per-domain TLS version and cipher suite control via `EdgionTls`

### Route Matching Engine

- **High-performance radix tree** with cache optimization and path variable support for Exact/Prefix route matching
- **Lock-free design** — route tables updated atomically via `ArcSwap`; zero locking on the request hot path

### Load Balancing & Resilience

- Algorithms: Round Robin, EWMA, Least Connections, Consistent Hashing, Weighted
- Active health checks
- Retry with configurable backoff, request timeouts, session persistence (Cookie / Header)

### Plugin System

25+ built-in HTTP plugins via `EdgionPlugins` CRD with plugin composition support:

**Authentication** — Basic Auth · JWT Auth · Key Auth · HMAC Auth · LDAP Auth · Forward Auth · OpenID Connect · JWE Decrypt · Header Cert Auth

**Security** — CORS · CSRF · IP Restriction · Request Restriction

**Traffic Management** — Rate Limit · Rate Limit (Redis) · Proxy Rewrite · Response Rewrite · Bandwidth Limit · Request Mirror · Direct Endpoint · Dynamic Upstream

**Observability & Utilities** — Real IP · Ctx Setter · Mock · DSL

**Gateway API Standard Filters** — Request/Response Header Modifier · Request Redirect · URL Rewrite

**Stream Plugins (TCP/UDP)** — IP Restriction

### Observability

- Unified access log: full request lifecycle in a single JSON line (routing, plugins, backend, errors)
- Prometheus metrics endpoint

### CLI

- `edgion-cli` — inspect and operate both Controller and Gateway
