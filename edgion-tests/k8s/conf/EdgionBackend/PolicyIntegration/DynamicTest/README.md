# AI Backend Policy Integration

The `AiBackendPolicyIntegration` dynamic scenario owns every mutable resource
whose name starts with `policy-integration-` and removes those resources after
the scenario. This directory only provides the shared Gateway listener that is
safe to retain across the full Kubernetes test run.

The scenario uses the in-cluster test server through these Service endpoints:

- HTTP: `http://edgion-test-server.edgion-test.svc.cluster.local:30001`
- HTTPS: `https://edgion-test-server.edgion-test.svc.cluster.local:30051`
- mTLS: `https://edgion-test-server.edgion-test.svc.cluster.local:30052`
- strict SNI: `https://edgion-test-server.edgion-test.svc.cluster.local:30026`

Backend trust and client identity reuse the `backend-ca` and
`backend-client-cert` Secrets generated by
`scripts/common/generate_runtime_certs.sh` during the prepare phase.
