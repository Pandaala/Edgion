## 一句话定位

> **Edgion** — 基于 Rust & Pingora 的现代 API 网关，为解决真实的网关工程问题而生。

## 六大核心优势

**28 个插件开箱即用，覆盖生产环境核心场景。**
26 个 HTTP 插件 + 2 个 Stream 插件，涵盖认证、安全、流控、可观测四大领域。7 种认证方式——BasicAuth、ForwardAuth、HeaderCertAuth、HMAC、JWT、KeyAuth、LDAP——无需拼凑第三方组件。6 个安全插件与 7 个流量控制插件一应俱全，一个网关覆盖你的核心需求。

**Rust 构建，性能与安全并重。**
基于 Cloudflare Pingora 框架打造，继承其久经大规模生产环境验证的高性能异步架构。Rust 语言从编译期杜绝内存安全隐患——没有空指针、没有数据竞争、没有缓冲区溢出。让你的网关既快又稳，既强又安全。

**内置沙盒 DSL 脚本引擎，灵活定制无上限。**
47 个内置函数，涵盖字符串处理、请求改写、条件判断、正则匹配等常见场景，无需编写插件即可在配置层实现复杂的业务逻辑。沙盒隔离机制确保脚本执行安全可控，即使表达式出错也不会影响网关主进程。降低开发门槛，提升运维效率。

**Kubernetes Gateway API v1 原生支持，独立部署同样从容。**
云原生与传统架构双模式并行。在 Kubernetes 环境中，原生对接 Gateway API 标准，声明式管理路由与策略；在非容器化环境中，支持独立二进制部署，配置文件驱动即可运行。无论你是 K8s 深度用户还是裸机运维老手，Edgion 都能无缝融入你的技术栈。

**极致可观测性，线上问题无所遁形。**
统一 JSON 格式访问日志搭配 21 个 Prometheus 指标，从请求延迟到上游健康，从连接数到错误率，关键数据一目了然。全链路协议覆盖 HTTP/1.1、HTTP/2、gRPC、TCP、UDP、WebSocket、SNI Proxy 七大协议，让每一次请求都有迹可循，每一个异常都有据可查。

**热重载一切，变更零中断。**
路由规则、插件配置、TLS 证书——所有变更实时生效，无需重启进程，无需排维护窗口。业务流量在配置切换的瞬间保持完全连续，真正实现零停机运维，让变更不再成为深夜加班的理由。
